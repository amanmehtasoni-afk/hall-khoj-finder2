# Hall Khoj Finder — Admin Control Center Guide (Phase 10)

## 1. Accessing Admin Panel
Navigate to `/admin/dashboard.html`. Only authenticated profiles with the verified `'admin'` role in `user_roles` can perform administrative operations.

## 2. Core Capabilities
1. **Overview & Analytics**: View total active venues, gross booking merchandise value (GMV), token advances collected, and pending KYC verification requests.
2. **KYC Queue**: Inspect submitted business documents (GST certificates, PAN, trade licenses) and mark owners `VERIFIED` or `REJECTED`.
3. **Listings Moderation**: Inspect newly registered marriage halls, verify photo authenticity, approve listings to go live, or suspend non-compliant vendors.
4. **User & Owner Management**: Search users, toggle account statuses between `ACTIVE` and `SUSPENDED`, and resolve reported disputes.
5. **Audit Logs**: Inspect the platform security trail capturing actor IDs, IP addresses, actions, and timestamps.
